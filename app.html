Channels & API

WhatsApp

live

Staff photograph a receipt and send it to this number. Matched to the person by the mobile they send from, so a number that has not been added and verified is ignored. Set centrally in BMS.

Email intake

live

Forward an invoice or booking confirmation. One mailbox serves every customer — the sender is resolved to an organisation, so the address is the same for everyone. Attachments and PDFs are both read, and the sender gets an acknowledgement on the same thread.

REST API

live

Third-party systems submit on a person's behalf. Identify them by staff_id, email or mobile; the sender still has to resolve to an active member of your organisation.
